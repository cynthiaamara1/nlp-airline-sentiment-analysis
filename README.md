# Airline Tweet Sentiment Analysis using Machine Learning and Deep Learning

## Project Overview

This project investigates sentiment analysis of airline-related tweets using Natural Language Processing (NLP). The goal is to automatically classify tweets into **positive**, **neutral**, or **negative** sentiment by comparing traditional machine learning algorithms with modern deep learning and transformer-based models.

The project evaluates Naive Bayes, Support Vector Machine (SVM), Long Short-Term Memory (LSTM), and BERT to determine which approach performs best on noisy social media text.

---

## Objectives

- Build an NLP pipeline for tweet sentiment classification
- Compare traditional and deep learning models
- Handle class imbalance in social media data
- Evaluate model performance using multiple metrics
- Identify the best-performing sentiment classification model

---

## Dataset

**Twitter US Airline Sentiment Dataset (Kaggle)**

Dataset characteristics:

- 14,640 airline tweets
- Three sentiment classes:
  - Positive
  - Neutral
  - Negative
- Real-world customer feedback collected from Twitter
